# MAIKA CRM 1.0.1

Android Chrome向けの、端末内で暗号化保存する顧客管理PWAです。

公開URL: https://akito0523-a11y.github.io/maika-crm/

## Androidで使い始める

1. 上記URLをAndroidのChrome（通常モード）で開きます。
2. 「オフライン利用の準備ができました」と表示されるのを確認します。
3. Chrome右上の「︙」→「ホーム画面に追加」→「インストール」を選びます。端末により表記が異なります。
4. ホーム画面のMAIKA CRMから起動し、長く推測しにくいパスコードを設定します。12文字以上を推奨します。
5. 架空の顧客を1件登録し、終了・再起動後にも残ることを確認します。
6. 設定・保護から暗号化バックアップを保存し、実データを登録する前に復元も試してください。
7. 一度オンラインで準備が完了した後、機内モードでも起動できることを端末で確認します。

## データと保護

- 顧客情報はブラウザ内でAES-256-GCM暗号化。パスコードからPBKDF2-SHA256（310,000回）で鍵を作ります。鍵は保存しません。
- 顧客情報・LINE履歴を外部送信する処理、解析API、広告、外部ライブラリはありません。初回起動と更新ではGitHubにアプリ本体を取りに行きます。
- GitHub Pagesとこのリポジトリは公開です。公開されるのはプログラムとアイコンであり、顧客データをここへアップロードしてはいけません。
- GitHubにはアクセス元のIPアドレス等が伝わります。「通信が一切ない」サービスではありません。
- 同じ `akito0523-a11y.github.io` 上の別アプリは同一オリジンです。サブフォルダはデータ保護の境界になりません。このドメイン上には信頼できるコードだけを配置してください。
- GitHubアカウントを保護し、未確認の変更を公開しないでください。配信コードが改ざんされると、ロック解除後の情報を読み取られる恐れがあります。
- ブラウザデータの消去・端末故障で情報を失うことがあります。定期的に暗号化バックアップを別の安全な場所に保管してください。別端末へは自動同期しません。
- パスコードを忘れると復元できません。以前のバックアップは、その保存時点のパスコードで復元します。
- 既存HTMLを直接開いて登録したデータは公開URLへ自動移行しません。旧アプリでバックアップし、新URLで復元してください。
- 5分間操作がなければロックします。アプリ切り替え時は画面をぼかし、復帰時にも経過時間を確認します。使用後は「今すぐロック」し、端末にも画面ロックを設定してください。

## 配信・更新

GitHub Settings → Pages → Deploy from a branch → main / (root) で配信します。HTTPSを有効にします。

すべてのアセット参照、manifestのstart_url・scope・id、Service Workerの登録は相対パスです。ルート配信とサブパス配信に対応します。

キャッシュはこのアプリのスコープ専用です。他サイトのキャッシュを消しません。更新する場合は `sw.js` のVERSIONも変更してください。新バージョンはアプリ画面をすべて閉じてから適用されます。更新前にバックアップを取得してください。

## 検証範囲

コード検査と自動テストで暗号化・復号、誤パスコードと改ざんの拒否、初期版バックアップ互換性、ロック時の表示消去、サンプルLINE抽出、サブパスでのアセット解決、キャッシュ削除の範囲とオフライン応答を確認しました。Android実機のインストールと端末固有の保存動作は利用端末で確認してください。
